## Key Technical Details

### Data Model (UNCHANGED)
The `IOutputData` interface in `html-types.ts` stays the same. The mapper produces this data object, and the template renders it. Only the template changes.

```typescript
interface IOutputData {
  tailwindStyles: string;      // → rename to bladesStyles
  tailwindElements: string;    // → DELETE (no JS)
  statistics: { passed, failed, notApplicable, notReviewed, profileError, ... }
  severity: { none, low, medium, high, critical }
  compliance: { level: string, color: string }
  files: { filename, toolVersion, platform, duration }[]
  resultSets: { filename, fileID, results: [...] }[]
  showResultSets: boolean;     // Manager/Admin only
  showCode: boolean;           // Admin only
  exportType: string;
  icons: { circleCheck, circleCross, ... }  // SVG strings
}
```

### Template Variables Available in Mustache
These are what the template can use — they come from the mapper:
- `{{exportType}}` — "Executive", "Manager", "Administrator"
- `{{{tailwindStyles}}}` → change to `{{{bladesStyles}}}`
- `{{{tailwindElements}}}` → DELETE
- `{{statistics.passed}}`, `{{statistics.failed}}`, etc.
- `{{severity.none}}`, `{{severity.low}}`, etc.
- `{{compliance.level}}`, `{{compliance.color}}`
- `{{#files}}...{{/files}}` — loop over loaded files
- `{{#resultSets}}...{{/resultSets}}` — loop over file results
- `{{#showResultSets}}...{{/showResultSets}}` — conditional
- `{{#showCode}}...{{/showCode}}` — conditional
- `{{{icons.circleCheck}}}` etc. — SVG icon HTML strings

### Blades CSS Installation
```bash
# Option 1: NPM (if you want to track versions)
npm install blades-css --save-dev

# Option 2: Vendor the file directly (simpler for embedding)
curl -o data/reverse-html-mapper/blades.standalone.css https://unpkg.com/blades-css/blades.standalone.css
```

For embedding in HTML export, Option 2 is better — just vendor the single CSS file.

### Blades CSS Key Patterns

**Accordion (replaces TW Elements JS accordion):**
```html
<details>
  <summary>V-2255 — htpasswd files must be protected</summary>
  <table>
    <tr><th>Status</th><td>Passed</td></tr>
    <tr><th>Severity</th><td>Medium</td></tr>
    <!-- ... -->
  </table>
</details>
```

**Card (replaces Tailwind div+classes):**
```html
<article>
  <header>Summary</header>
  <p>Passed: 40 | Failed: 6 | NR: 6</p>
  <footer>Compliance: 76.92%</footer>
</article>
```

**Table (auto-styled):**
```html
<table class="striped">
  <thead><tr><th>Control</th><th>Status</th><th>Severity</th></tr></thead>
  <tbody>
    <tr><td>V-2255</td><td>Passed</td><td>Medium</td></tr>
  </tbody>
</table>
```

**Nav (replaces Tailwind sticky nav):**
```html
<nav>
  <ul><li><strong>Administrator Report</strong></li></ul>
  <ul>
    <li>Passed: 40</li>
    <li>Failed: 6</li>
  </ul>
</nav>
```

**Dark mode (automatic):**
```html
<html lang="en">
  <head>
    <meta name="color-scheme" content="light dark" />
    <style>{{{bladesStyles}}}</style>
  </head>
  <!-- Blades auto-switches based on prefers-color-scheme -->
```

**Print CSS (add to template):**
```css
@media print {
  .no-print { display: none; }
  details > summary ~ * { display: block !important; }
  details > summary::marker { display: none; }
}
```

### Tab Navigation Replacement
Current template uses TW Elements JS tabs for file switching. Options:
1. **Sections with anchor links** — simplest, each file is a `<section id="file-{fileID}">`, nav links to them
2. **Radio button hack** — CSS-only tabs using `<input type="radio">` + `:checked` + sibling selectors
3. **Just show all files** — for exported reports, tabs may be unnecessary. Show all files in sequence with clear section headers.

Recommendation: Option 3 for V1. The exported HTML is a document, not an app. Show all data with clear headings.

## Risk: Android HTML Viewer

The current template has this warning:
```html
<!-- WARNING: Tailwind Elements interactive components get disabled on Android's HTML viewer; use a browser instead -->
```

With Blades CSS + native `<details>`, this warning is no longer needed. `<details>/<summary>` works natively in Android's HTML viewer and every modern browser.
